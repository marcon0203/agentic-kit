# spec-17-fe-bundle-editor Bundle 可视化编排

> 对应任务 `task_implement.json#17` | 依赖：#15 fe_console、#7 bundle_center
> 关联：docs/架构设计文档_AI-Agent平台_V1.md、docs/PRD_AI-Agent平台_AgentBundle编排与运行_V1.md、api/openapi.yaml

## 目标

Bundle 编排图的可视化拖拽编辑（PRD P1-1）。

## 技术选型

React Flow（`@xyflow/react`）。POC 阶段用手写 SVG 验证了只读渲染，编辑场景工作量大，用成熟库。

## 功能

- 从左侧 Agent 面板拖拽节点入画布
- 连线定义 edges，支持并行分支（一对多）
- 节点右键配置 human gate（超时秒数、超时策略）
- 边上配置 `condition` 表达式
- 可视化 ↔ DSL 源码双向切换（源码编辑后回填画布）
- 保存前调用后端图校验，问题边高亮标红

线框图见 PRD 六.2。

## 验收清单

- [ ] 拖拽连线生成的 DSL 与手写等价
- [ ] 并行分支正确渲染为一对多连线
- [ ] human gate 配置面板可设置超时与策略
- [ ] 源码模式编辑后能正确回填画布
- [ ] 保存时图校验失败，对应边高亮并显示原因
- [ ] 自环重试边能被正确绘制（视觉上区别于普通边）

## UI/UX设计

> 遵循 `design-system.md`，复用 `ds-graph-node` 组件。本页是编辑态画布，与 spec-14 的只读执行图共用节点视觉语言但交互完全不同。

### 页面布局

```
┌──────────┬──────────────────────────────┬──────────────┐
│ Agent 面板│  画布（React Flow）             │ 属性面板      │
│ 可拖拽列表 │                                │ 选中节点/边时  │
│           │   [product_manager]            │ 显示配置项     │
│ 搜索框     │         │                      │              │
│ ○ PM      │         ▼                      │ human gate:  │
│ ○ 架构师   │   [architect] ⚠gate            │ 超时 [1800]s │
│ ○ UI设计师 │      /      \                  │ 策略 [中止▼] │
│ ○ 全栈     │     ▼        ▼                 │              │
│           │  [ui]      [fullstack]↺        │              │
├──────────┤                                ├──────────────┤
│ [+新建]   │  [画布][DSL 源码] ← ds-tab      │ ( 保存并校验 ) │
└──────────┴──────────────────────────────┴──────────────┘
```

三栏比例约 240px / 1fr / 300px，中间画布自适应。画布底用 `surface-muted` 加浅点阵，与 `surface` 的节点形成层次。

### 视觉语言（与执行图的区别）

| 元素 | 只读执行图（spec-14） | 编辑画布（本任务） |
|---|---|---|
| 节点色 | 按运行状态（5 种语义色） | 统一 `surface` + `border`，**不用状态色**（编辑态没有运行状态） |
| 选中态 | 无 | 2px `primary` 边框 + 品牌渐变细光晕 |
| 校验错误 | 无 | `error` 边框 + 节点角标叹号 |
| 连线 | `border-strong` 实线 | 同上；hover 时加粗并显示删除按钮 |
| 自环重试边 | `warning` 虚线 | 同左（保持一致，帮助用户建立映射） |
| human gate | 节点后独立胶囊 | 节点右上角 `warning` 色角标 + 图标 |

### 关键交互流程

**拖拽建节点**：从左侧面板拖 Agent 到画布 → 落点生成节点 → 自动选中并聚焦右侧属性面板。

**连线建边**：节点边缘拖出连接点 → 拖到目标节点 → 生成边。一个源节点连多个目标时自动识别为并行分支，边上显示「并行」chip。

**条件边编辑**：选中边 → 右侧属性面板出现表达式输入框 → 输入时实时语法校验（`expr-lang` 语法），错误时 `input-error` 红边框 + 下方说明。

**双向切换**：`ds-tab` 在「画布」和「DSL 源码」间切换。源码用等宽字体 + 语法高亮，编辑后切回画布自动回填；**源码有语法错误时禁止切回画布**，并在错误行标红。

**保存校验**：点「保存并校验」→ 调后端图校验 → 失败时问题边/节点变 `error` 态并抖动一次（尊重 `prefers-reduced-motion`），右侧面板列出全部问题及原因，点击问题项定位到对应元素。

### 各状态呈现

| 状态 | 呈现 |
|---|---|
| Empty（新建空画布） | 画布中央虚线面板 + 「从左侧拖入第一个 Agent 开始编排」+ 箭头指向左侧面板 |
| Loading（加载已有） | 画布骨架 + 中性灰 |
| Error（校验失败） | 问题元素标红 + 右侧问题清单，**不阻止继续编辑** |
| Error（源码语法错） | 源码 tab 内错误行标红 + 底部错误条，禁用切回画布 |
| Success（保存成功） | Toast「已保存」+ 问题清单清空 |
| 未保存变更 | 顶部「有未保存的更改」提示条 + 离开页面前浏览器确认 |

### 响应式

编辑器需要横向空间，**≤900px 不提供编辑能力**，改为只读预览 + 提示「请在更大屏幕上编辑编排图」。这是刻意取舍：勉强适配小屏会得到一个难用的拖拽体验。

## UI验收标准

- [ ] 编辑画布节点**不使用运行状态色**，统一 `surface` + `border`
- [ ] 自环重试边用 `warning` 虚线，与 spec-14 只读图视觉一致
- [ ] human gate 在节点右上角以 `warning` 角标 + 图标呈现（不只靠颜色）
- [ ] 一对多连线自动识别并标记「并行」chip
- [ ] 条件表达式输入实时语法校验，错误时红边框 + 下方文字说明
- [ ] 「画布 / DSL 源码」双向切换，源码修改能正确回填画布
- [ ] 源码存在语法错误时**禁止**切回画布，并标出错误行
- [ ] 图校验失败时问题边/节点标红且右侧列出原因，点击可定位
- [ ] 校验失败**不阻止**用户继续编辑
- [ ] 空画布显示引导文案和指向左侧面板的提示
- [ ] 有未保存变更时，顶部提示条 + 离开页面前确认
- [ ] 抖动等提示动效遵守 `prefers-reduced-motion`
- [ ] ≤900px 时降级为只读预览并给出明确说明
- [ ] 画布支持键盘操作：Tab 遍历节点、Delete 删除选中、方向键微调位置
- [ ] DSL 源码区使用等宽字体
