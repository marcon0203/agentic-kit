# spec-18-operation 运营中心

> 对应任务 `task_implement.json#18` | 依赖：#11 run_engine、#13 fe_foundation
> 关联：docs/架构设计文档_AI-Agent平台_V1.md、docs/PRD_AI-Agent平台_AgentBundle编排与运行_V1.md、api/openapi.yaml

## 目标

运营中心：运行监控、成本报表、审计日志、举报处理。

## 功能清单

| 功能 | 要点 |
|---|---|
| 运行列表 | 按 Bundle/状态/时间筛选，失败项一键跳时间线 |
| 成本分析 | 按天/周/月聚合 Token 与成本，支持导出 |
| 审计日志 | human gate 审批记录，append-only，不可篡改 |
| 举报处理 | 管理员查看举报队列、下架资源（通知存量订阅者） |

## 设计约束

Operation Service **只做聚合和展示，不承担业务逻辑**，通过订阅其他服务的事件/日志获取数据，不直接读其他服务的业务表——保证各服务可独立演进。

## 验收清单

- [ ] 运行列表筛选与分页正确
- [ ] 失败运行可跳转到完整时间线定位原因
- [ ] 成本报表数据与 `bundle_runs` 累计值一致
- [ ] 审计日志不可编辑删除（数据库层保证）
- [ ] 管理员下架资源后，存量订阅者收到通知且资源标记不可用

## UI/UX设计

> 遵循 `design-system.md`。本任务虽非 `fe_` 前缀任务，但包含运行列表、成本报表、审计日志、举报处理四组界面，同样需要设计规范约束。

### 页面布局

顶部 `ds-tab` 四个视图（监控中心 / 调用日志 / 成本分析 / 审计日志），正好落在 2-6 个推荐区间。

**运行监控**：指标行（今日运行数 / 成功率 / Token 消耗 / 成本，四个 Metric 共享数值基线）→ 筛选工具栏 → 运行列表表格。

**成本分析**：时间粒度 `ds-tab`（日/周/月）→ 折线图 → 明细表格 + 「导出」次按钮。

### 表格设计

- 表头用 `label-md`，单元格 `body-md`，元信息列（时间、run_id）用 `caption` + 等宽字体
- 状态列用状态胶囊（图标 + 文字，不只颜色）
- 行 hover 加 `surface-muted` 底
- 失败行的「查看原因」为文字按钮，点击跳转到该次运行的 Chat 页并自动切到「时间线」tab 定位到失败事件

### 图表配色

折线图主线用 `colors.primary`，对比线用 `colors.secondary`；**不使用品牌渐变填充大面积区域**。多条线时除颜色外还需**不同线型（实线/虚线/点划线）**，保证色盲用户可区分。坐标轴与网格线用 `border`，标签用 `caption`。

### 审计日志的特殊要求

审计日志强调不可篡改，视觉上**不提供任何编辑/删除入口**，行尾只有「查看详情」。每条记录展示：操作人 + 操作类型 + 对象 + 时间（精确到秒，等宽字体）+ 结果。human gate 审批记录额外显示审批意见。

### 各状态呈现

| 状态 | 呈现 |
|---|---|
| Loading | 表格骨架 8 行 + 指标区骨架 |
| Empty（无运行记录） | 虚线面板 + 「还没有运行记录」+ 「去应用中心发起一次运行」主按钮 |
| Empty（筛选无结果） | 虚线面板 + 「当前条件下没有记录」+ 「清除筛选」次按钮 |
| Empty（无举报） | 虚线面板 + 「暂无待处理举报」（无操作按钮——这是正常的好状态，不需要引导动作） |
| Error | 内联错误面板 + 重试 |
| Loading（导出中） | 按钮转 loading 态并禁用，防止重复点击 |
| Success（导出完成） | Toast「报表已导出」，文件自动下载 |
| Success（下架完成） | Toast「已下架」+ 列表行即时更新为「已下架」状态，无需刷新 |

### 下架操作的安全设计

管理员下架资源是**破坏性操作**，用 `button-danger` + 二次确认弹窗。弹窗需明确说明影响范围（「该资源有 56 个存量订阅者，下架后他们将无法继续使用」），确认按钮文案为「确认下架」而非泛泛的「确定」。

### 响应式

| 断点 | 行为 |
|---|---|
| 901–1260px | 指标行 4→2 列，表格横向滚动 |
| ≤900px | 指标堆叠，表格改为卡片列表（每行一张卡片） |

## UI验收标准

- [ ] 四个视图 Tab 使用统一 `ds-tab` 样式
- [ ] 指标行多个 Metric 共享同一数值基线，数值用 `data` 字体
- [ ] 表格状态列用胶囊（图标 + 文字），不只靠颜色
- [ ] 时间、run_id 等数据列使用等宽字体
- [ ] 失败行可一键跳转到该运行的时间线并定位失败事件
- [ ] 折线图多条线除颜色外还有不同线型，色盲用户可区分
- [ ] 图表未使用品牌渐变做大面积填充
- [ ] 审计日志行**无编辑/删除入口**
- [ ] 审计记录时间精确到秒
- [ ] 下架操作用 `button-danger` + 二次确认，弹窗说明影响的订阅者数量
- [ ] 下架确认按钮文案为「确认下架」，不是泛泛的「确定」
- [ ] 弹窗 footer 为「取消 + 一个主操作」，没有孤立的「关闭」
- [ ] 三种空态（无记录/筛选无果/无举报）文案与操作各不相同
- [ ] 「暂无待处理举报」空态不强行放操作按钮
- [ ] 导出中按钮为 loading 且禁用，完成后有 Toast
- [ ] ≤900px 时表格降级为卡片列表
