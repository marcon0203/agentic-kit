# spec-13-fe-foundation 前端基础设施

> 对应任务 `task_implement.json#13` | 依赖：#1 app_init
> 关联：docs/架构设计文档_AI-Agent平台_V1.md、docs/PRD_AI-Agent平台_AgentBundle编排与运行_V1.md、api/openapi.yaml

## 目标

前端设计系统、布局导航、路由、API client 与认证弹窗。

## 设计系统

**以 `design-system.md` 为唯一来源**（数值来自 `tokens-pc.md`）。本任务负责把它落成 CSS 变量：

- 色板：`primary` / `secondary` / ink 三级文字 / surface 三级表面 / border 两级 / 语义色
- 字体层级：`display` ~ `caption` 全套，衬线用于标题、无衬线用于功能 UI
- 间距（4px 基准 `space-1`~`space-12`）、圆角（`rounded.xs`~`full`）、阴影三级
- 平台状态语义映射：等待中→`ink-500`、运行中→`primary`、待审批→`warning`、完成→`success`、失败→`error`

> 早期 POC 的深色控制台配色（`--bg-canvas` 等）**作废**，改用浅色系统。详见本文末「UI/UX设计」。

## 导航结构

对应 IA V4 六大模块：首页 / 应用中心 / 资源中心 / 模型中心 / 运营中心 / 系统设置，外加应用广场入口。

## API client

从 `api/openapi.yaml` **生成** TypeScript 类型（`openapi-typescript`），不手写——保证前后端契约一致。

封装统一信封解包：`code !== 0` 时抛出带业务错误码的异常，供上层按 code 分支处理（不匹配 message 文案）。

## 验收清单

- [ ] 六大导航 + 广场入口可正常跳转，当前项高亮
- [ ] 未登录访问受保护路由自动跳转登录页
- [ ] token 过期时自动尝试 refresh，失败则登出
- [ ] API 类型由 openapi 生成，`tsc --noEmit` 通过
- [ ] 设计系统 CSS 变量覆盖全部状态色，无硬编码颜色值

## UI/UX设计

> 遵循 `design-system.md`。本任务是全站视觉基线，所有数值取自 `tokens-pc.md`，其他 spec 不得覆盖。

### ⚠ 两处必须修正的上游偏差

1. **改为浅色系统**。本 spec 原文写的深色控制台配色（`--bg-canvas` 等）作废，改用 tokens：页面底 `surface-page #f6f7fb`，卡片 `surface #ffffff`，主文字 `ink-900`，正文 `ink-700`，元信息 `ink-500`。
2. **登录注册改为弹窗，删除独立路由**。原文的「登录/注册页 + 鉴权路由守卫」不成立——认证是全局身份组件，以 `modal` 形式存在于 app shell 内。守卫逻辑保留，但触发的是弹窗而非页面跳转。

### App Shell 布局

```
┌────────────────────────────────────────────────────────┐
│ 顶栏 64px  Logo │ 六大导航 + 广场 │        用户头像/登录  │  surface + 底部 border
├────────────────────────────────────────────────────────┤
│                                                          │
│   container-app 1380px，左右至少 24px 边距                │  surface-page
│                                                          │
└────────────────────────────────────────────────────────┘
```

- 顶栏固定，`surface` 底 + 底部 1px `border`；导航项用 `body-md`，激活项 `tab-active` 色 + 2px 下划线
- 主内容区统一 `container-app`（1380px），**不逐页重定义**
- 页面模块间距 `space-10`(64)，卡片栅格间隙 `gutter`(24)

### 认证弹窗

610px 宽，`navy-950`→`navy-900` 渐变底 + 中心柔光，圆角 `rounded.xl`。标题用 `title-modal`（PingFang SC，**不用衬线**）。一个通栏主提交按钮，第三方登录为次要描边按钮。`Escape`/关闭键/遮罩点击均可关闭且不改变认证状态。深色底上阴影不透明度降低，避免脏灰边。

### 状态呈现基线（全站复用）

| 状态 | 呈现 |
|---|---|
| Loading | 骨架屏，中性灰微光，**绝不用品牌渐变**；遵守 `prefers-reduced-motion` |
| Empty | 虚线边框面板，**同时给出原因 + 下一步操作按钮** |
| Error | 内联错误面板 + 重试按钮；表单错误必须边框 + 文字双重提示 |
| Success | Toast 底部居中距边 28px，停留 2-3 秒，同时只有一个 |

### 响应式

| 断点 | 行为 |
|---|---|
| >1260px | 完整桌面布局 |
| 901–1260px | 卡片栅格降为 2 列，工具栏可换行 |
| 721–900px | 工作台收为单列，侧栏移至顶部 |
| ≤720px | 全单列，操作按钮通栏，弹窗接近全屏 |

## UI验收标准

- [ ] 全站无深色控制台残留，页面底为 `surface-page`，卡片为 `surface`
- [ ] 登录注册以弹窗呈现，浏览器地址栏**不出现** `/login` 之类的独立路由
- [ ] 认证弹窗支持 Escape、关闭按钮、遮罩点击三种关闭方式，关闭不改变认证状态
- [ ] 主内容区宽度为 `container-app` 1380px，各页面一致，无局部覆盖
- [ ] 顶栏导航激活态同时有颜色和下划线两种区分（不只靠颜色）
- [ ] 骨架屏为中性灰，未使用品牌渐变
- [ ] 开启系统「减少动效」后，所有加载动画停止
- [ ] 键盘 Tab 可遍历顶栏全部导航项，焦点环 3px 可见且未被移除
- [ ] 所有可点击元素命中区域 ≥ 40×40px
- [ ] 正文文字与背景对比度 ≥ 4.5:1（`ink-700` on `surface` 需实测通过）
- [ ] 中文正文无小于 12px，可操作文字无小于 13px
