# spec-15-fe-console 资源与应用管理页

## 目标

资源中心、Agent 定义、Bundle 列表等管理页面。

## 页面清单

| 页面 | 要点 |
|---|---|
| 首页工作台 | 我的应用/智能体、最近访问、快速创建、运行监控、Token 消耗 |
| 资源中心 | 四类资源列表（Tab 切换）、注册表单、启停 |
| Agent 定义页 | 映射 Agent DSL 全字段的表单，线框图见 PRD 六.1 |
| Bundle 列表 | 列表 + 版本历史 |

## Agent 定义表单

按 PRD 线框图分区：基本信息 / 模型配置 / 角色设定 / 能力白名单 / 执行约束 / 协作契约。

**表单校验复用后端同一份 JSON Schema**（`schemas/agent.schema.json`），用 `ajv` 在浏览器端实时校验，避免"前端过了后端不过"。

能力白名单的资源选择器从资源中心拉取，已禁用资源置灰不可选。

## 验收清单

- [ ] Agent 表单覆盖 DSL 全部字段，保存前实时校验
- [ ] 校验错误精确定位到对应表单项并标红
- [ ] 「从现有 Agent 复制」预填全部字段
- [ ] 订阅来的资源在列表中带「订阅」标识与作者信息，且不可编辑
- [ ] 资源禁用后，Agent 表单中该项置灰并提示原因

## UI/UX设计

> 遵循 `design-system.md`。本任务页面多为表单与列表，重点在表单校验的视觉反馈。

### 页面布局

**首页工作台**：`container-app` 内三段式——指标行（Metric 组，三个共享数值基线）→ 快捷入口卡片栅格（3→2→1 列）→ 最近访问列表。

**资源中心**：顶部 `ds-tab` 切换四类资源（tool/skill/mcp/知识库，正好落在推荐的 2-6 个区间）→ 工具栏（搜索 `input` + 「注册资源」主按钮）→ 表格或卡片栅格。

**Agent 定义页**：单列表单，按 PRD 线框图分六个区块，每区块用 `headline-sm` 标题 + `space-7` 分隔：基本信息 / 模型配置 / 角色设定 / 能力白名单 / 执行约束 / 协作契约。表单最大宽度 720px（长表单不铺满 1380px，避免视线横向移动过长），右侧留空或放置校验摘要。

### 关键交互流程

**表单四段校验**（设计系统硬性要求）：输入时、失焦时、前置操作前、提交时；**提交时重新校验**，不信任早先的通过状态。

- 校验通过：`input-valid` 的 `mint` 边框，**不加冗余的"成功"文字**
- 校验失败：`input-error` 红边框 **+ 字段下方明确错误信息**，不能只给边框
- 后端返回的 `details[].field` 精确映射到对应表单项，滚动到第一个错误项并聚焦

**能力白名单选择器**：从资源中心拉取，已禁用资源置灰不可选，hover 时显示禁用原因 tooltip。

**从现有 Agent 复制**：预填全部字段，`agent` ref 自动追加 `-copy` 后缀并聚焦该字段提示用户修改。

**订阅资源的呈现**：列表中带「订阅」chip + 作者信息，行尾操作区**不显示编辑按钮**（黑盒资源不可编辑），只有「进入使用」。

### 各状态呈现

| 状态 | 呈现 |
|---|---|
| Loading（列表） | 骨架行 5 条，中性灰 |
| Empty（首次无资源） | 虚线面板 + 「还没有注册任何资源」+ 说明用途一句话 + 「注册第一个资源」主按钮 |
| Empty（搜索无结果） | 虚线面板 + 「没有找到匹配的资源」+ 「清除筛选条件」次按钮（与上一种空态文案和操作都不同） |
| Error（加载失败） | 内联错误面板 + 「重试」按钮 |
| Success（保存成功） | Toast「已保存」+ 跳转到列表并高亮新建行 2 秒 |

### 响应式

| 断点 | 行为 |
|---|---|
| 901–1260px | 卡片栅格 3→2 列，工具栏换行 |
| 721–900px | 工作台单列，表单仍保持 720px 上限 |
| ≤720px | 全单列，表单通栏，操作按钮通栏 |

## UI验收标准

- [ ] 资源中心四类 Tab 使用统一 `ds-tab` 样式，未逐页重定义颜色/圆角
- [ ] Agent 表单最大宽度 720px，未铺满整个容器宽度
- [ ] 表单在输入、失焦、提交三个时机均触发校验，提交时重新校验
- [ ] 校验失败：红边框**和**字段下方文字提示同时出现，缺一不可
- [ ] 校验通过：mint 边框，**没有**多余的"校验通过"文字
- [ ] 后端 `details[].field` 能精确定位到表单项并自动滚动聚焦
- [ ] 已禁用资源在选择器中置灰，hover 显示禁用原因
- [ ] 「从现有 Agent 复制」预填全部字段且 ref 自动加后缀
- [ ] 订阅来的资源带「订阅」chip 和作者信息，且无编辑入口
- [ ] 「首次无数据」与「搜索无结果」两种空态的文案和操作按钮不同
- [ ] 每种空态都同时给出原因和下一步操作
- [ ] 表单标签用 `label-md`，helper 文字用 `caption`
- [ ] 输入框高 48px、圆角 13px，焦点态有品牌蓝边框 + 4px 光环
- [ ] 每个操作组内只有一个主按钮
- [ ] 表单错误通过 `aria-describedby` 关联到输入框

### 补充：模型 Provider 与用量（P0-14 / P0-17）

**Provider 接入页**（模型中心）：卡片列出三家 Provider，未接入的显示「接入」主按钮，已接入的显示状态 chip + 「更换密钥」次按钮。API Key 输入框类型为 password，保存后**永不回显**（显示为 `sk-••••••••`）。

**未接入时的全站拦截**：任何运行入口（首页快速创建、Bundle 列表的「运行」、广场的「进入使用」）在用户未接入任何 Provider 时**置灰**，hover 提示「请先在模型中心接入模型 Provider」并提供跳转链接——不是让用户点了才报错。

**工作台用量卡片**：`data` 字体显示本月 Token 与成本，下方 `caption` 显示环比；点击进入按 Bundle 分组的明细。

补充验收项：
- [ ] 未接入 Provider 时，全站运行入口置灰并提示跳转，而非点击后报错
- [ ] API Key 保存后不回显，只显示掩码
- [ ] Provider 接入时做连通性校验，失败给出具体原因（非泛泛的"接入失败"）
- [ ] 工作台展示本月个人用量与成本，可下钻到 Bundle 维度
- [ ] 删除资源前展示占用影响（被哪些 Agent/Bundle 引用）
- [ ] 已被订阅的版本删除入口置灰并说明「已有订阅者，只能停止分发」
